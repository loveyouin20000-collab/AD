**Goal:** Enforce the frozen B1 execution profile before torch import and
produce a deterministic, source-only 32-sample MVTec tiny split.

An immutable runtime object applies and attests torch settings. A pure split
builder shares identical scientific-content construction between side-effect-
free dry-run and atomically written official execution.

the existing production MVTec adapter, and existing atomic artifact utilities.
